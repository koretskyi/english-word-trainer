# English Word Trainer

React-приложение для изучения английских слов и аудирования.

## Запуск на Windows

1. Установи Node.js 22 и Python 3.12.
2. Установи FFmpeg и проверь, что команда `ffmpeg -version` работает в новом терминале.
3. Дважды нажми `START_APP.bat`.
4. При первом запуске BAT-файл создаст Python-окружение и установит зависимости. Затем откроются два окна: локальный Whisper API и Vite.
5. Открой `http://localhost:5173/`.

Оба окна терминала должны оставаться открытыми, пока пользуешься приложением.

## Локальное распознавание речи

Режим «Аудирование» записывает звук в браузере и отправляет его на локальный адрес `/api/transcribe`. Vite проксирует запрос в Python API на `127.0.0.1:8000`, где работает `faster-whisper small` с CPU INT8.

- Распознавание выполняется на этом компьютере.
- OpenAI API key не нужен.
- Аудио не отправляется во внешний сервис.
- FFmpeg преобразует запись браузера в WAV 16 kHz mono; Python передаёт массив напрямую в faster-whisper, обходя несовместимость декодера PyAV.
- При первом запуске модель может скачаться из Hugging Face (около 484 МБ); последующие запуски используют кэш.
- Для проверки API: `http://127.0.0.1:8000/health`.

Зависимости Python находятся в `backend/requirements.txt`, код API — в `backend/main.py`.

## Требования

- Node.js 18+ (рекомендуется 22).
- Python 3.12.
- FFmpeg в PATH.
- Интернет нужен для установки зависимостей и первоначальной загрузки модели.

## Данные

Учебные предложения и прогресс хранятся в `localStorage` текущего браузера. Они не синхронизируются между устройствами. Админка не защищена паролем.

## Сборка React-приложения
