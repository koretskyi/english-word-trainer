# English Word Trainer — MVP v1

Минимальное React-приложение для изучения английских слов через предложения. Backend и база данных пока не используются.

## Самый простой запуск на Windows

1. Распакуй архив целиком в папку.
2. Убедись, что установлен Node.js 22.11.0 или новее в ветке 22.x. Для совместимости с установленным у тебя Node.js в проекте используется Vite 6, а не `vite@latest`.
3. Дважды кликни `START_APP.bat`. При первом запуске он установит зависимости через npm, затем запустит приложение.
4. Открой в браузере URL, который появится в терминале, обычно `http://localhost:5173/`.
5. Не закрывай окно терминала, пока работаешь с приложением.

Если BAT-файл не запускается, открой терминал в папке проекта и выполни:

```bash
npm install
npm run dev
```

## Требования

- Node.js 18 или новее. Конфигурация Vite 6 подходит для Node.js 22.11.0.
- npm (устанавливается вместе с Node.js).
- Интернет нужен при первом `npm install`, чтобы скачать библиотеки.

## Что реализовано

- 10 примерных учебных карточек.
- Поле ввода находится внутри английского предложения на месте пропущенного слова.
- Подсказки показывают скрытые и открытые буквы; позиции открытых букв задаются в админке.
- Проверка ответа без учёта регистра и пробелов по краям.
- Навигация по карточкам.
- Локальная админка: добавление, редактирование и удаление предложений.
- Сохранение содержимого в `localStorage` этого браузера.
- Адаптивный интерфейс для мобильных и настольных экранов.

## Как добавить предложение

В админке заполни:

- Русское предложение: `Я оставил пальто в машине.`
- Английский шаблон: `I left my {word} in the car.`
- Пропущенное слово: `coat`
- Открытые буквы (позиции начиная с 1): `3`
- Уровень: `A2`

`{word}` должно встречаться в английском шаблоне ровно один раз. В этой версии изучаемое слово должно быть одним словом без пробелов.

## Важно

Админка пока не защищена паролем. Данные хранятся только в текущем браузере и не синхронизируются с другими устройствами. Не очищай данные сайта в браузере, если хочешь сохранить добавленные предложения.
